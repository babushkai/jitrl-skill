Run the JitRL stats command to show experience statistics:

```bash
python3 "$CLAUDE_PLUGIN_DIR/scripts/jitrl.py" stats
```

Display the results in a formatted table showing:
- Total experiences stored
- Positive vs negative score distribution
- Most common action types
- Average score
